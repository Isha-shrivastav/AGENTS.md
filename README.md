# Ghost Data Still Exists — Starter Package

## Run the demo
- Windows: double-click `run.bat`, or open CMD in this folder and run `python code/main.py`.
- The program reads `dataset/deletion_requests.csv` and writes `output.csv` in this folder.

## Important
The included dataset is only a 3-row DEMO so you can confirm that the script runs.
It is NOT the official HackerRank dataset and its predictions are NOT ready for submission.
For the challenge, replace the demo `dataset/` with the original full dataset, preserving its
files and evidence folders. Then rerun the agent and validate the output.
